Rédige une réponse Outlook à partir de ton intention.

Tu ouvres un mail, tu dis ce que tu veux (ex. « c’est noté, je reviens demain »), l’IA propose un texte, tu l’insères. Mode confidentiel par défaut : le corps du mail n’est pas envoyé à l’IA.

Télécharger le manifeste Voir le panneau

1. Lis

Le complément récupère le mail ouvert dans Outlook.

2. Dis

Tu écris ou dictes ton intention, pas un prompt compliqué.

3. Insère

Tu relis, tu colles dans Outlook. Ta signature Outlook reste la tienne.

Installer dans Outlook (en attendant le Store)

Aujourd’hui il faut ajouter le fichier manifeste une fois. Ensuite le bouton Bot Mail IA apparaît sur tes mails.

  1. Télécharge manifest.xml.
  2. Outlook classique Windows : Fichier → Gérer les compléments / Get Add-ins → Mes compléments → Ajouter un complément personnalisé → Ajouter à partir d’un fichier.
  3. Choisis le manifest.xml téléchargé.
  4. Ouvre un mail, clique Bot Mail IA.

Le Microsoft Store (AppSource) est l’étape suivante : là, n’importe qui pourra l’installer sans fichier XML. En attendant, ce sideload marche pour tester et pour un petit groupe.

Gratuit, mais avec des limites

L’IA tourne sur Groq. Pour que tout le monde puisse s’en servir, chaque adresse IP est limitée (10 générations / 15 min, 40 / jour). Si tu construis un usage intensif en entreprise, le déploiement centralisé Microsoft 365 ou une clé Groq dédiée sera plus adapté.
